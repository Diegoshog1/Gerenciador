# Modelo de planilha para Google Sheets (Viagens)

Arquivo: `planilha_viagens_google_sheets.csv`

## Como usar
1. Abra o Google Sheets.
2. Vá em **Arquivo > Importar > Upload**.
3. Envie o arquivo `planilha_viagens_google_sheets.csv`.
4. Escolha **Substituir planilha atual** (ou **Inserir nova planilha**).

## O que a planilha já calcula
- **Duração da viagem (dias)** pela diferença entre data de ida e volta.
- **Gasto real total** somando passagem, hospedagem, seguro, alimentação, passeios e transporte local.
- **Diferença vs orçamento** para mostrar quanto sobrou (positivo) ou excedeu (negativo).

## Dicas rápidas
- Preencha datas no formato da sua localidade (ex.: `2026-07-10`).
- Use a coluna **STATUS** para organizar o funil das viagens.
- Se quiser novas linhas, copie uma linha existente para manter as fórmulas.
